# Film 3: what training builds, and what scale changes

The film is an opener (`script_open.md`) followed by seven stops. Each stop's lab, saved results, script and narration check are in its own folder:

| Stop | Folder |
|---|---|
| 1. Induction heads, layer by layer | `../../parts/s12-induction` |
| 2. Relations and outer-product memory | `../../parts/s13-relations` |
| 3. Attention as memory: softmax to the delta rule | `../../parts/s17-memory` |
| 4. Scaling laws | `../../parts/s16-scaling` |
| 5. mu-P | `../../parts/s15-mup` |
| 6. Grokking: why the rule wins | `../../parts/s14-grokking` (numbers from `lab.py` here and `../../grokking/`) |
| 7. The 2026 frontier models (dated snapshot) | `../../parts/s18-frontier` |

`lab.py` in this folder computes the grokking, implicit-bias and double-descent numbers (and the earlier derivation checks) that stop 6 reads. `youtube.md` has the chapters and references of the published film.
