# Understanding Transformers (advanced series)

Code for the advanced follow-up to *Intro to Transformers* on the AI Notes channel. Every number shown in an episode is produced by code here; the claims about our own measurements have tests.

- Videos: [the playlist](https://www.youtube.com/playlist?list=PLSQN85XNghpY)
- Written guide: [Understanding Transformers: what they compute, and what they need](https://flavianv.github.io/articles/understanding-transformers.html)
- Bonus episode on real LLMs: AbstractGym ([part 1](https://youtu.be/QIBMdjqpPAs), [part 2](https://youtu.be/q38WEwK3fEI)), code in [flavianv/abstractgym-public](https://github.com/flavianv/abstractgym-public)

It builds on `tlib` (the intro series' GPT, attention and RoPE in the repo root): install the repo once with `pip install -e ".[dev]"`.

Run scripts from this directory with `PYTHONPATH=.`; results land in `results/a1` … `results/a5`. `tools/run_a1_a2_all.sh`, `tools/run_a3_all.sh` and `tools/run_a4_all.sh` run every job, 4 at a time, at the lowest CPU priority. Every experiment uses three seeds (0, 1, 2); the models are tiny and train in minutes on a CPU.

Tests: `pytest advanced-transformers/tests` from the repo root. `test_a<N>_results.py` pins every number shown in episode A<N> against the saved results; the other test files check the library itself.

The notebooks are generated by `tools/make_nb_a<N>.py`.

The running example is a 3-state machine: A rotates 0→1→2→0, B swaps 0 and 1, I does nothing; the task is the final state after a list of actions.
